very simple scripts that just fetches hotel data from 'agoda.com', a client side rendered website and in the future from 'booking.com' server side rendered


nearly same script is written in both javascript and python

* to run python script:
1 - install python
2 - cd into the root of the this repository "dataAnalysis/"
3 - type "python main.py" if it threw error try "py main.py" if not "pip main.py" if non worked check if you correctly installed python and have it's path set up


* to run javascript script:
1 - install node
2 - cd into "/dataAnalysis/javascript/" and run "npm install" (this will install needed libraries automatically)
3 - cd back into "/dataAnalysis" (just "cd ..")
4 - type "node main"
